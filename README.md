## 📌 Sobre

O **FinanceHub** é uma plataforma web de gestão financeira desenvolvida para facilitar o controle de receitas, despesas, orçamentos e metas financeiras.

O projeto oferece uma experiência moderna, intuitiva e responsiva, permitindo que o usuário acompanhe sua vida financeira por meio de dashboards, relatórios e indicadores.

---

## ✨ Funcionalidades

- Dashboard financeiro
- Cadastro de receitas
- Cadastro de despesas
- Controle de orçamento
- Metas financeiras
- Relatórios
- Tema claro e escuro
- Armazenamento Local (LocalStorage)
- Interface responsiva

---

## 🛠 Tecnologias

- HTML5
- CSS3
- JavaScript ES6
- LocalStorage
